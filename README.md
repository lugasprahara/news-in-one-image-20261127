The world news of Friday 27 November 2026 in a single 1024x1024 image: 33 stories — a hero panel on the widening Iran war (two Italian technicians killed in Kuwait, tankers hitting mines at Hormuz), 12 story panels from the EU's stalled Ukraine loan to Congo's Ebola outbreak and three buzzer-beating NFL finishes, 20 one-line briefs, and a world map dotted where each numbered story happened. The image is drawn programmatically by render.py (Python + PIL) from the day's reporting; main.ts copies the finished entry.png to the output directory the harness reads.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
